PRIVACY NOTICE / DRAFT

Privacy, plainly.

This notice describes the intended privacy practice for the public website and API. It takes effect only when the service is publicly launched and may be updated before launch.

What the website collects

The public website does not ask visitors to create an account and does not intentionally use advertising trackers or analytics cookies. The live explorer sends its search term to the service to return matching public procurement signals.

Our hosting provider and API gateway may process standard technical data needed to operate and protect the service, such as IP address, request time, browser metadata, request path, and error logs.

API customers

API subscriptions, payment details, and account identity are handled by the selected API marketplace or payment provider under that provider's privacy notice. JP Signals receives only the information needed to authenticate, rate-limit, support, and secure API access.

How data is used

Technical data is used to operate the API, detect abuse, diagnose failures, enforce rate limits, and improve reliability. We do not sell visitor information or use it for targeted advertising.

Retention and contact

Operational logs are retained only as long as reasonably necessary for security and reliability. Before launch, the public contact address and final retention period will be added here.

This is a launch-stage product notice, not legal advice. Obtain a jurisdiction-appropriate review before accepting paid subscriptions.
